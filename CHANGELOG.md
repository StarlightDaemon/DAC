# Changelog

## 0.1.0 development candidate — 2026-10-08

- Establish independent standalone native Windows application history and versioning.
- Port MIT-licensed per-display policy, native presentation, settings, profiles,
  schedules, slideshow, saver hosting, and diagnostics from the historical project.
- Carry forward the R01C wake counters, attribution boundaries, and regression matrix.
- Replace injected host integration with an ordinary Win32 executable and owned lifecycle.
- Generate native Fujin theme values from the verified v0.1.0 dependency checkout.
- Add CMake builds, private-desktop regression execution, and portable package checks.

This is a new product version line. The historical Windhawk v0.3.0 release is
not the immediately preceding version of standalone DAC. Qualification and
remaining limitations are recorded separately; this entry is not a production
readiness claim.
